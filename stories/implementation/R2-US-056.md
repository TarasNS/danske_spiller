## Retry (W-ADV round 2, narrowed)
Cause 1: after a wrong answer the browser scrolls while the feedback is appended; `scrollIntoView({block:"nearest"})` then put the box top at viewport top 0, under the sticky `.sd-bar` (rendered 56 px, token says 48 px). Cause 2: after Næste the new question rendered while the page was still scrolled down; focus used `preventScroll`, so question and first option were above the viewport.
Change (`adverbs.html`, `shared/themes/adverbs.css`):
- New helpers next to `focusFirstControl`: `stickyBarH()` (measures the real `.sd-bar`), `scrollFeedbackIntoView()` (feedback top >= bar + 12 px, bottom <= viewport - 16 px, top wins), `scrollGameIntoView()` (keeps `#game` top below the bar). Instant (`scrollBy`, no smooth), so reduced motion is respected.
- `showAnswerExplanation` calls `scrollFeedbackIntoView()` after adding Næste (game code, no longer dependent on `sjovt.js`); the Sjovt hook calls the same helper after its restyling (replaces `scrollIntoView`).
- `loadQuestion` calls `scrollGameIntoView()` (when the learner has interacted) before `focusFirstControl()`.
- CSS: `#feedback { scroll-margin-top: 72px; scroll-margin-bottom: 16px }` as a belt-and-braces fallback.
Nothing else changed (unlock levels, no timed advance after wrong, correct auto-advance, Lyt labels, gap ".", storage).

Measurement (`impl\r2-adv\v.mjs`, Edge): 7 modes x 3 viewports (1366x768, 390x844, 360x640) x reduced motion on/off x 2 start scroll positions (top / bottom) = 84 wrong answers, then Næste via Enter on each.

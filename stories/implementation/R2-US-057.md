# R2-US-057 — Dansk Mester: wrong-answer note stays readable (W-DM round 2)

Status: IMPLEMENTED

## 1. Implementation summary
- `finishAnswer()` (dansk-mester.html ~l.1003-1032): after a WRONG answer in flervalg / blandet / intervalrepetition / svage ord, no `G._adv` timer is scheduled. A "Fortsæt →" button (`#btn-continue-q`, `.btn`, >=44 px, keyboard focusable) is appended to the feedback box, receives focus (`preventScroll`) and is scrolled into view with `block:'nearest'` (`behavior:'auto'` under reduced motion, else smooth); `scroll-margin-bottom:16px` keeps it off the viewport edge so the note and replay button above it are fully visible. The click calls `nextQuestion()` (guarded by `G` and `#gamewrap`).
- Correct answers unchanged: 750 ms advance. Timed mode (`Tidsudfordring`) keeps its own pace (1500 ms advance on wrong/timeout, unchanged, by the brief). Match and vendekort untouched.
- Cleanup: "Fortsæt ▸" -> "Fortsæt →" at the match result (~l.1155) and results screen (~l.1207). No "▸" remains.
- `clearGameTimers`/`quitGame` unchanged; wrong path now has no timer at all.

# US-009 - Forvekslingspar serves only answerable items

Status: IMPLEMENTED (worker W-PREP; not VERIFIED)

## 1. Implementation summary
`randItem(filter)` in `dansk-praepositioner.html` now falls back in this order: (level AND filter) -> (filter, all levels) -> level pool -> all ITEMS. With a pair filter the last two are never reached because every group has items. `nextPair` additionally requires `it.a` to be one of the two pair options (`p.a`/`p.b`). Other modes pass no filter (or `hasSafeErr`) and behave as before.

# US-002 - Forbindeord: stop offering valid synonyms as wrong options

Status: NEEDS REVIEW (implemented and tested; native-speaker sign-off on synonym/overlap tables outstanding)

## Implementation summary
File: `forbindenor/Forbindenor.html` only (function `distractors`, now preceded by a safety block).
- Old logic: 3 distractors from the answer's own category (+ unfiltered fallback to all answers).
- New logic: a distractor must not be (1) the answer or in an explicit synonym group with it (`SYN_GROUPS`, checked both ways), (2) from a category that overlaps the answer's category (`CAT_OVERLAP`; a category always overlaps itself), (3) a "wildcard" connector that fits nearly any frame (`WILDCARD`: faktisk, altså, også, nemlig, endda, nu, dog, alligevel, så). It must also fit the same word-order slot class (`slotClass`: conjunction-type vs adverbial; "så" is a conjunction only in Konsekvens). If fewer than 3 remain, only the slot-class restriction is relaxed, never the synonym/overlap exclusions.
- Distractors are therefore always cross-category, never from a category whose members can fill the slot with the same meaning. This is approach (a)+(b) from the story. Because doubtful distractors are excluded rather than the key being widened, no `accepted` list was needed.
- Exclusions are deliberately generous (over-excluding only shrinks the pool; min pool size is 5 per item with slot class kept, so nothing is starved).
- Unchanged: `cat`/`catEn` (display, stats), `LS_KEY`, `perWord`/`perCat` keys, scoring, data rows, `records`, `byCat`, `allAnswers`.
- Synonym groups cover all clusters listed in the story (Eksempel, Holdning probability/naturligvis-selvfølgelig/desværre-uheldigvis, Konsekvens, Forklaring, Tid, Opsummering) plus a few more (især/specielt, omsider/endelig/til sidst, mens/hvorimod, dvs./m.a.o./det betyder, tilføjelse cluster, contrast adverbs).

## Remaining risks
- Cross-category distractors are grammatical but semantically different. In sentences like "Vi ses {}" (answer senere) a Holdning word such as "muligvis" is syntactically possible but changes the meaning; the English translation disambiguates. Not judged a synonym.
- Quantifier items (både/begge/alle/hverken/ingen af dem) get adverbial distractors, which are trivially wrong by syntax (no quantifier-specific slot class).
- Item-level slot position is not modelled (answer-word level only), e.g. midfield vs sentence-initial adverbs.
- Because distractors are now never same-category, the category no longer hints the answer; difficulty profile changes (arguably easier on meaning, harder on slot syntax).
- "Items allowing several connectors get an accepted list or are rewritten" is satisfied by excluding doubtful distractors, not by an `accepted` list; the key itself was not rewritten.

- The "exclude known overlaps" approach (`CAT_OVERLAP`, asymmetric) is replaced by a strict WHITELIST of word kinds. Every answer word has a kind: `CAUSC` fordi/da/eftersom/idet/for, `CONTRC` men/mens/hvorimod/selvom, `COMPC` ligesom, `EXC` som, `QUANT` baade/begge/alle/hverken/ingen af dem/dels, `PREP` pga., `CONTRPREP` i modsaetning til, `UCONJ` dvs./m.a.o., `ATCL` det betyder/sammenfattende kan man sige, `EXADV` eksempelvis/fx/bl.a./endda, `EXADV2` isaer/specielt, `TCONJ` foer, `SAAC` "saa" as consequence conjunction, `MOD` Holdning adverbs, `ADV` all other adverbials.
- `KIND_PAIRS` is a list of unordered pairs of kinds that cannot fill the same frame; the matrix `KIND_OK` is built from it in both directions, so it is symmetric by construction (the test checks it).
- Decisions taken from the actual frames: all adverbial kinds (Tid, Raekkefoelge, Tilfoejelse, Konsekvens adverbs, Opsummering, Uddybning, contrast adverbs, Eksempel adverbs, time words) are NEVER paired with each other, because after "og"/";"/a clause any of them gives a natural Danish sentence. Contrast conjunctions are not paired with causal ones (men/selvom fit "Jeg blev hjemme, ___ jeg var syg"). Eksempel adverbs and "som" are not paired with additive/continuing adverbs or "dvs.". Quantifiers are not paired with adverbs ("Hun er formentlig klog og venlig"). Fronted-object frames (i modsaetning til) are not paired with fordi/dvs./det betyder (main-clause order after them is natural).
- Holdning/modal adverbs are answer-only (kind `MOD`, and any word whose category is Holdning): never offered as distractor for any item. Holdning answers get only distractors that cannot fill a modal-adverb slot (fordi/eftersom/idet, men/mens/hvorimod/selvom, det betyder, sammenfattende kan man sige, i modsaetning til).
- `WILDCARD` (never offered): faktisk, altsaa, ogsaa, nemlig, endda, nu, dog, alligevel, saa, da, for, som, ligesom, foer, samtidig, kort efter, dels, kort sagt, alt i alt, afslutningsvis, pga., eksempelvis, fx, bl.a., isaer, specielt (words that fit almost any frame or can start a clause without inversion; they can still be ANSWERS and use the matrix for their own distractors).
- `SYN_GROUPS` kept, extended with altsaa/dvs./m.a.o./det betyder and det betyder/sammenfattende.
- Per-item `ITEM_EXCL` (idx, expected answer, words; ignored if the answer at that index does not match): 36, 38 (foer + clause: no dvs./det betyder), 62, 102, 167-172, 174, 175, 177 (initial or fragment frames where dvs./det betyder/subordinators read naturally), 191, 192, 227, 347-350 ("Endelig, at ..." exclamative). `ITEM_ADDKIND` for item 172 (adds adverbials as distractors because every conjunction/restatement reads naturally there). No `accepted` list was needed: with this whitelist no offered distractor remains that I am confident reads naturally; doubtful ones are excluded rather than the key widened.
- Slot-class rule: now part of the kinds (conjunctions CAUSC/CONTRC/SAAC vs adverbials ADV/MOD). The old "prefer same class" tier was dropped because the whitelist never admits a same-slot word (see risks).

Status: NEEDS REVIEW (code and data changes done; the native-speaker sign-off the story requires is outstanding)

## 1. Implementation summary
All in `dansk-praepositioner.html`.
- `gen()` takes new opts: `noErr` (item gets `err:null`, excluded from Find fejlen / Ret sætningen), `wrong` (explicit distractors), `not` (valid alternatives never offered as wrong options). Item fields `noErr`, `wrong`, `not` added; `reviewQ` entries gain `wrong`/`not` (additive; old stored entries still work).
- `distractorsFor(prep,n,item)` uses `item.wrong` first, then CONFUSE, and excludes `item.not` (also from the random padding). All four callers (mc, drag, speed, review) pass the item.
- Mistake/correct modes use a shared `hasSafeErr` filter (also checks `noErr`).
- `CONFUSE`: removed the self entries (af in af, fra in fra, uden in uden).
- QA-104: coffee ("kaffe med ..."), tea ("te uden ..."), "Temperaturen er under ..." now use `err:"af"` (ungrammatical in every fill) and lost their `pair` (both options valid). "Hun rejste uden ..." and "Mødet sluttede uden ..." are `noErr:true` and lost `pair`.
- QA-105: `not` lists added for: kantinen (ved), "Vi ses på" (ved), "Bogen ligger på" (i; reolen/hylden/sengen split out as noErr), "Han sidder stadig i" (toget/sofaen split out as noErr, not på), "Hun sidder ved" (i, på; err now "af"), "Han står og venter ved" (i, på; err now "af"), "Huset ligger ved" (på; err now "til"), "Katten ligger under" (i, ved), "Det skete under" (i), "Reglerne gælder under" (i), "under udvikling" (i), "Vi spiser efter" and "Han kom efter" (under), "Vi gik over" (på), "Mødet varede over" (under), "Der var over ... til stede" (under), "færdig om en time" (på; err now "af"; pair removed).
- QA-106: "Vi skal lige nå til flyet..." replaced by "Vi skal lige nå frem til stationen/hotellet/havnen/lufthavnen" (answer "til"); "Bilen holder ved indkørslen" split into its own item "Bilen holder i indkørslen" (answer "i", noErr, wrong til/for/med); the two "Brevet er ..." frames now differ: "Brevet er adresseret til ..." and "Vi har fået et brev fra ..."; TRANS entries accept an optional 5th element array of alternative answers (farmor/bedstemor, "Tak for din hjælp", "Jeg bliver færdig om en time").
- Enter in the text inputs now calls `preventDefault` (needed because focus moves to Næste in US-013; otherwise the same keypress also activated Næste).

# US-048 - Forbindeord: resume mid-run, minor language (W-FORB)

Status: NEEDS REVIEW (resume IMPLEMENTED; some content left for native/owner decision)

## Summary
Resume: new key `forbindenor_run_v1` (LS_KEY `forbindenor_v1` untouched) stores {v, sig, i, order, score, streak, lives, opts, pick}. Saved at every render (unanswered item) and after every answer (with the chosen option). On load it is validated strictly (version, data signature = item count + hash of sentences, order is a permutation, value ranges, saved options contain the answer, pick is one of the options); any failure -> fresh run. Reload restores the same item, same option order, score, streak and lives; an already answered item is restored in its answered state (correct/wrong marks, reveal, Næste) without re-scoring. Weak mode is not persisted. Cleared at end of run, on restart and on reset. All storage access guarded.

Language corrections applied (clear cases only):
1. "Så" notes: the three Konsekvens "så" items with no inversion ("Det regnede, så vi blev hjemme", "Han trænede hårdt, så han vandt", "Vi var sultne, så vi lavede mad") no longer carry "Står ordet først… verbet før grundleddet". ("Vejen var glat, så kørte vi langsomt" keeps its inversion note; Tid-"så" items unchanged.)
2. "For det andet" without "for det første": items 314/315/316 rewritten so "for det første" appears (English translation updated): "Jeg blev hjemme. For det første var jeg syg, og {} havde jeg ingen energi." / "For det første sparer vi penge, og {} bør vi tænke på miljøet." / "For det første er pladsen lille, og {} er den dyr."

# US-005 - Adverbier: repair the core loop (review, mode rotation, answer leak, input handling)

Owner: W-ADV. Status: IMPLEMENTED

## 1. Implementation summary
All in `adverbs.html` (+ small CSS in `shared/themes/adverbs.css`). Storage key `danishSentenceBuilderProgress` and the US-004 localStorage guards are unchanged.
- **Zone and rotation:** `startZone` stores `currentZone`; every `loadQuestion(mode, zone)` call carries the zone (default = active zone). Each zone run uses a shuffled rotation of the 7 modes (`MODE_ROTATION`); after one full rotation the boss round (5 questions from the same zone: meaning/gap/translate/order/category) runs, titled "Bossrunde n/5 - <mode>", then a new rotation starts. Boss uses its own `bossActive/bossQueue` and no longer shares review state. An empty zone shows a Danish "no words yet" message instead of crashing. An entry whose category has no button falls back from Ordklasse-jagten to Udfyld hullet.
- **Review:** the Repetition button opens the modal with the word list ("mangler N rigtige svar") and a new "Start repetition" button; starting closes the modal, then the first question renders (options clickable). While a review runs the button reads "Fortsæt repetition" and an "Afslut repetition" button appears. "Luk" only hides the modal (play area untouched). A correct review answer increments `mistakes[w].completed` (or `savedWords[w]`), the modal list refreshes live, and the word leaves review at 0. The empty-queue check now runs after the wrong-answer re-queue, so "Repetitionen er færdig!" shows after the last item (with a "Tilbage til øvelserne" button). A pending 2 s auto-advance timer is cancelled when a zone/review starts (it could double-advance before).
- **Answer leak:** Bindeordsduellen shows the full sentence with the target word blanked (`blankWord`, whole-word, Unicode-aware; same helper as Udfyld hullet) instead of splitting at the comma.
- **Input handling:** the global keydown ignores events from input/textarea/select/[contenteditable], Ctrl/Meta/Alt combos and any open dialog, and no longer hijacks Enter on a focused button (before, Enter on a word tile also submitted the order). R opens review from anywhere (before: only while a question was pending).
- **Undo:** Ordstilling tiles toggle (click a placed tile to remove it) and there is a "Fortryd sidste ord" button; tiles carry `aria-pressed`; a live preview shows the sentence built so far. All real buttons, so Enter/Space work.
- Sjovt fx hooks (wrapped `handleAnswer`/`renderGame`/`updateDashboard`) keep working. Category mode now uses the page's `#options` div instead of creating a duplicate id.

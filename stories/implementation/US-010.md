# US-010 - Bøjningsværkstedet: shuffle options in modes 5 and 6

Worker: W-BOEJ

## 1. Implementation summary

- Modes 5 (`bestemt_ubestemt`) and 6 (`maengdevaerkstedet`) are the only modes that use the choice render path (`makeMcRenderer`, `boejningsvaerkstedet/index.html`). Modes 1-4 are free-text or tile modes and were not touched.
- The renderer now builds a per-presentation shuffled copy `shownOptions = shuffle(item.options.slice())` (using the file's existing Fisher-Yates `shuffle`, same pattern as `pronomenmysteriet`). Buttons, the `choose(i)` lookup (`shownOptions[i]`), the reveal-correct highlight and the 1-n number keys all use that displayed order. The check compares the chosen option text with `item.correct` (it already did, via `DC.diff.normalize`, never index 0).
- Item data, SRS keys (`item.id`, `pattern:`), scoring and the 800 ms auto-advance are unchanged.

# US-006 - Adverbier: Danish TTS replay on prompts and wrong-answer feedback

Owner: W-ADV. Status: IMPLEMENTED (real Danish-voice listening check still open: U-05)

## 1. Implementation summary
- `adverbs.html` loads `shared/dansk-speech.js` then `shared/dansk-core.js` (before the game script) and uses `DanskCore.ui.ttsButton` (class `dc-tts-button`; `da-DK` is set inside `DanskCore.tts.speak`). `shared/dansk-core.js` was not touched; no shared dependency.
- Replay buttons (44x44, aria-label "Afspil igen" from core) on: Find betydningen (the word), Udfyld hullet and Bindeordsduellen (the sentence with the blank skipped, so the audio never reveals the answer), Ordklasse-jagten (the word), Lyt og vælg (full sentence), and in the answer feedback (correct and wrong) replaying the Danish sentence. Oversættelsesbroen (English prompt) and Ordstilling (scrambled tiles) have no Danish prompt before answering; they get the replay button in the feedback.
- **Lyt og vælg:** the sentence text is never shown (the old 3 s reveal is gone); prompt: "Lyt til sætningen. Hvilket af ordene hører du?" plus a replay button. The sentence is spoken once on render, but only after the learner has interacted with the page, so no autoplay on load. Distractors never occur in the spoken sentence. If the device has no Danish voice (`hasDanishVoice()` false) the mode falls back to a blanked gap-fill and says so.
- Styling for buttons inside `.tts-row` in `shared/themes/adverbs.css` (does not override the class itself; US-029 can still restyle centrally).

## 6. Remaining risks
- Gap prompts are read with a pause where the word is missing; it may sound odd.
- `ttsButton` registers one `voiceschanged` listener per button created (core behaviour, small leak).
- Edge/Chrome may block speak() without a gesture; the listening autoplay is gated on interaction and the replay button always works.

## 7. Newly discovered issues
- `ttsButton` always labels buttons "Afspil igen"; screen-reader users cannot tell what is replayed (core change).

## 8. Needs native review
Audible quality of gap prompts with the blank removed; wording of the Lyt og vælg prompt.

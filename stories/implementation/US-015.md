## 1. Implementation summary

- QA-080 (M5): the four subject-owner items that taught hans/hendes for sin were rewritten so the owner is a different person from the sentence subject (the `b5-hans-bil` approach). Keys, options and item IDs are unchanged, e.g. "Peter er ikke kommet endnu. Jeg så ___ ved stationen." -> `hans cykel`. Notes now say the owner is not the grundled.
- QA-081 (M6): `b6-nogen-peter` key is now `noget`, note "Fast udtryk: se noget til nogen."
- QA-082: `rig` moved from the -ig list to `REG_WORDS` in `shared/data/adjectives.js`; `rig-sammenligning` is now rigere / rigest (accepts rigeste, den/det rigeste).
- QA-083 (M4): `superlative_definite` for periphrastic adjectives is now `'mest ' + definite/plural form` (adjEn, adjPeriphrastic, træt, interessant). blå/grå and indeclinables are unchanged because their plural equals the base. `data.js` still builds `[sup, supDef, 'den '+supDef, 'det '+supDef]`, so "den mest typiske" is accepted and "den mest typisk" rejected (bare "mest typisk" still accepted).
- QA-084: new adjective field `irregular_comparison` (true only for god, dårlig, gammel, lille, mange, få, stor, ung, lang, nær). `irregular` keeps its neuter-quirk meaning. M4 note/`comparison_type` use `irregular_comparison`; glad/flot/let now read "Glad gradbøjes regelmæssigt: gladere -> gladest." and are `comparison_type: 'regular'`.
- QA-085 (M4): `NON_GRADABLE` filter in `data.js` excludes mulig, umulig, offentlig, kongelig, færdig, gyldig, ugyldig, lovlig, ulovlig, forskellig (10 items removed from M4; 186 -> 176).
- QA-086 (M6): five `intet` items whose noun has identical singular/plural now use nouns with a distinct plural (vindue, æble, værelse, billede, talent); nine `begge` items got an explicit "to" cue; four `hverken` items got a negative cue.
- QA-087 (M5): 26 generic-plural items got a generic cue ("I almindelighed" / "Generelt"); five fixed-expression/specific items were reworded (`b5-ligge-i-seng`, `b5-laese-avis`, `b5-til-middag`, `b5-manden-butik`, `b5-starte-i-skole`).
- QA-088 (M1): `fireFormerNote` now derives the note from the real change (consonant doubling, schwa loss, -um -> -et, dropped -e before -ne) via `definiteSingularNote` / `definitePluralNote`; the generic wording is kept only where it is true; unclassifiable forms get a neutral "x -> y" note.
- `shared/data/nouns.js` was not changed (no noun data error needed fixing; `lærer` already yields `lærerne`).

- Fixed-expression items (`i seng`, `læse avis`, `til middag`, `begynde i skole`) remain partly idiomatic; `sengen`/`middagen` are still conceivable in some contexts.

## 1. Implementation summary
- **Fit:** `.xpm-monitor` width is now `min(100%, (100dvh - 330px) * 1.2)` (with a `vh` fallback), centred. At 1366x768 the controls end inside the panel with no scrolling; at 360x740 the cap does not bite.
- **Mobile label:** the entry button shows `HJÆLP` (with the play glyph) at <=420 px and `FORKLARING` above; the `aria-label` "Hjælp: se en forklaring" contains the visible label. 78x44 px at 360.
- **Events and timers:** `modal.js` dispatches `explainer:open` when the dialog is shown and `explainer:close` when it is removed (CustomEvent on `document`, `detail.ids`). Exactly one close follows each open; closing during loading emits nothing. The four countdown games listen: they hold/stop the timer on open and on close resume only what they paused, and only if the same round is still running (time left > 0, game screen visible). Details per game in section 5.
- **Load failure:** if the player or every scene fails to load, the dialog opens with the Danish text "Forklaringen kunne ikke indlæses. Luk og prøv igen, eller genindlæs siden." (`role="alert"`, Luk button focused, Esc/backdrop/focus trap work, events still fire). If only some scenes fail, the rest are shown. A Tab press while still loading no longer throws.
- **Rule card centring:** root cause was the empty `.xp-sent` row (padding 0.6em each side) sitting next to the card in the flex stage. It is now `display:none` while the stage is in rule mode. Margin difference measured 13 px (360) / 23 px (1366) before, <=2 px now.
- **Tokens:** panel, buttons, tabs and the error box use `var(--sd-panel)`, `--sd-panel-2`, `--sd-primary`, `--sd-on-primary`, `--sd-text`, `--sd-line`, `--sd-ink`, `--sd-cream`, `--sd-focus`, `--sd-bad-bg`, `--sd-box`, `--sd-drop`, `--sd-ease` (all with literal fallbacks). The old hard-coded mustard panel and navy dark palette are gone; dark mode now follows the game's own tokens. Easing: `steps()` for the panel entrance, hover transitions and the player's default animation easing (was `ease-out`). Uppercase labels: modal title, tabs, controls, badges. Monitor art not redrawn (optional, skipped).
- **Scene chooser (supporting fix for US-025):** the tab list is one horizontally scrolling row (44 px targets, `scroll-snap`, edge fade where more tabs exist). The active tab is scrolled into view. Roving tabindex: Tab enters the strip on the active tab then continues to the controls; Left/Right (wrapping), Home and End switch tabs and keep focus. Tidsmaskinen's 10 tabs now take 57 px of height instead of ~7 rows.
- **Badge gate (US-035):** the "Skal tjekkes" badge is created only when `scene.verify` and `devMode()` (`?dev=1` in the URL or `localStorage["sd-dev"]==="1"`, both in try/catch). The header bar can wrap and the title wraps instead of ellipsizing, so titles are no longer truncated on mobile.
- Skill doc updated (`SKILL.md`: pause sentence replaced, events, dev flag, chooser, template sync direction). `templates/explainer.js|css` re-synced from `shared/explainer/`.
- Optional "open on the tab matching the active mode": not implemented (needs per-game mode knowledge; follow-up).

- ArrowRight on a focused tab now switches tabs instead of stepping the video (it still steps the video when focus is elsewhere in the panel).
- A game's own auto-advance `setTimeout` (about 800 ms after an answer) is not paused, so a question can advance behind an open dialog; only countdowns were in scope.
- Games whose theme does not define the `--sd-*` tokens would get the light fallbacks even in dark mode (all 10 current games load `sjovt.css`).
- Monitor art is still the 48x40 sprite (optional redraw skipped).

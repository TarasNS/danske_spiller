# US-007 - Adverbier: dataset, categories, unambiguous items, Danish grammar notes

Owner: W-ADV. Status: NEEDS REVIEW (native sign-off and owner decision on dataset size outstanding)

## 1. Implementation summary
Scope kept to QA-evidenced fixes; the dataset was NOT expanded or restructured (size is an owner decision from `specs.md`). Entry words and category strings that progress uses are preserved except the required retags.
- **Categories:** `derfor` ("Adverb - Cause/Effect") now has a button "Årsag og følge". `stadig` retagged to "Adverb - Time". `alligevel` retagged to "Adverb - Sentence" with a new button "Sætningsadverbium". `categoryKey()` maps each entry to a `CATEGORY_BUTTONS` key; an unknown category (e.g. from CSV) no longer yields an unanswerable question: it is asked as Udfyld hullet. `catDa` knows "Sentence" for "Svageste emne".
- **Levels re-assessed:** men, ud, inde A1; fordi, når, da, derfor, endnu, stadig A2; alligevel B1 (levels are not used by game logic).
- **Unambiguous items:** new optional `alt` per entry (words that would also fit), excluded from the options of gap-fill, Bindeordsduellen and Lyt og vælg: fordi: da; når: da; da: når; stadig: endnu, alligevel; endnu: stadig, alligevel; alligevel: stadig. In Lyt og vælg distractors also never occur in the spoken sentence.
- **Feedback:** wrong answer shows "Det rigtige svar er <answer in the asked form>" (word for gap/connector/listening, English meaning for Find betydningen, Danish sentence for Oversættelsesbroen/Ordstilling, category label for Ordklasse-jagten), the Danish sentence with replay, one Danish grammar note, and the English sentence only as a small "Engelsk hjælp" line. New per-entry `note` field (Danish) for all 10 entries; entries without a note (CSV) get a generic Danish category note.
- **Conjunctions:** fordi/når/da/men stay in the "Bindeord" zone with conjunction categories (correct for Bindeordsduellen/Ordklasse-jagten); nothing removed.
- **CSV:** the import modal text lists the optional `note` column. Old CSVs still import. An optional `alt` column (semicolon separated) is understood but not documented in the modal.
